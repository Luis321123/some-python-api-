## 📖 About

A **template** for a Python API: FastAPI app inside `app/`, Alembic
migrations, Docker + Compose, an env file and a small startup script —
everything needed to scaffold a new service quickly.

## ✨ Features

- FastAPI application template
- Alembic migrations included
- Docker + `docker-compose.yml` ready
- `startup.sh` and `.env.local` for configuration
